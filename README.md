# SAQnet: антифишинг-сайт (версия 2)

Белый сайт с тёмно-синими деталями. Языки: русский и казахский.
Зависимостей нет: нужен только Node.js 18 или новее (nodejs.org).

## Запуск
1. Распакуйте архив и откройте папку, где лежит `server.js`.
2. В терминале этой папки выполните: `node server.js`
3. Откройте http://localhost:3000 (окно терминала не закрывайте).

## Что умеет сайт
- **Проверка ссылки**: подделка брендов (Kaspi, Halyk, eGov и др.), IP вместо домена, подозрительные зоны, сокращённые ссылки, скрытые символы.
- **Проверка сообщения**: вставьте текст SMS, письма или мессенджера. Сайт ищет давление срочностью, запугивание, просьбы кода из SMS, денег, удалённого доступа, обещания выигрыша. Ссылки внутри текста проверяются отдельно. Понимает русский и казахский.
- **20 примеров** мошенничества с поиском и фильтром по темам.
- **Тест** из 8 вопросов.
- **Новости о мошенничестве в Казахстане**: автоматически из Google Новостей (кэш 30 минут). Если связи нет, показываются избранные материалы.
- **Куда звонить**: 102, 1477 (Нацбанк), 111, а также номера банков для блокировки карты. Номера проверены по материалам Нацбанка и банков в ноябре 2026.
- **Форма «Сообщить о фишинге»**.

## Ключи (по желанию)
Скопируйте `.env.example` в `.env`, вставьте ключи после `=`, перезапустите сервер.

| Ключ | Что включает | Где получить |
|---|---|---|
| GSB_API_KEY | база угроз Google | Google Cloud Console: Safe Browsing API |
| VT_API_KEY | база VirusTotal | virustotal.com, профиль, API key |
| ANTHROPIC_API_KEY | объяснение от Claude | console.anthropic.com |

Без ключей сайт работает на собственном анализе. Ключи хранятся только на сервере.

## Жалобы на почту
Сейчас жалобы сохраняются в `reports.jsonl`. Чтобы они приходили на email:
1. Выполните `npm install`.
2. В `.env` заполните `REPORT_EMAIL` и `SMTP_*` (для Gmail нужен пароль приложения).

## Публикация
Любой хостинг с Node.js (VPS, Render, Railway), команда запуска `node server.js`.
За прокси добавьте в `.env`: `TRUST_PROXY=1`. Для домена включите HTTPS.

## Файлы
- `server.js`: сервер и API (`/api/check`, `/api/message`, `/api/news`, `/api/report`)
- `public/index.html`: весь сайт
- `public/logo.png`, `public/mark.png`: логотип
